# Prism components

These SVG components come from the same material factories as the animated wall in `bridge/prism.js`. Run `node scripts/export-prism.cjs` from the repository root to reproduce them. The renderer changes each Line's two colors and animates tubes and connector rim sections independently; the exported files are useful for composition and inspection, while the live UI calls the factories directly.

The owner-provided Prism finish kit is the art source. Its archive SHA-256 is `ceef5c07993fa3aba77daae02521747fbb55d1c8595002231a378d06105f8fb0`. The detailed tube shell, front facets, light packet, diffuse spill, connector pane and permanent rim functions retain that source. The application adapts timing, roots, input handling and lifecycle for issue #53. No tray assets are included.

Canonical tube coordinates span x = −128…128 and y = −16…16. Runtime tube width is 78% of that height. A connector has radius 25 and flat-face distance `25 × cos(30°)`. Zone 0 belongs to endpoint `a`, zone 1 to endpoint `b`, even when deployment starts at `b`. Six quadrilateral rim pieces remain the connector's final border.

The served component paths are `/assets/prism.js`, `/assets/prism-adapters.js` and `/assets/prism-labels.js`. The SVG exports do not create an arbitrary browser file route. Ship all three JavaScript files beside `wall.html` and `wall_server.py`. The existing source inclusion lists contain them. The separately owned [Linux installation #54](https://github.com/jimmie-potts/codex-nanoleaf/issues/54), published in [PR #57](https://github.com/jimmie-potts/codex-nanoleaf/pull/57), must include all three JavaScript files in its runtime copy list when reconciling this source. Its Python-file glob does not include JavaScript. The packaged foreground smoke test in `tests/test_prism_assets.py` verifies the wall and all three assets without a Windows helper. No runtime path points to the original personal art folder, and no remote assets are required.

`prism-labels.js` places measured number envelopes against final screen geometry. The wall owns font measurement and the browser-local show-all preference; the renderer owns selection, highlight, hover and focus reasons. The placement helper reserves at least 24 by 24 screen pixels per click target and 11-pixel text, including the pending-ring envelope and a two-pixel gap. The six connector rims keep their own animation. Number visibility never moves neighbouring labels or restarts the flow clock.

Search is deterministic, bounded to 50,000 nodes, and cached by geometry, viewport and measured font dimensions. Unexpected unsolved labels stay hidden with an explanatory notice and accessible Line controls. A missing placement asset disables show-all with a repair notice. The actual-layout browser matrix must place every number; the fallback does not count as acceptance of an overlapping or incomplete supported layout.
