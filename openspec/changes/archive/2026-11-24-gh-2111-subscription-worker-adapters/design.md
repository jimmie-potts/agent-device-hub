## Ownership and handoff

Keep the coordinator's connection-bound endpoint and original operation
identity. Add coding-family versions for harness declarations, selected
starts and progress. Preserve earlier schema layouts. An absent selection
means Claude Code. Send alternate work only to a worker that declares it.

The worker owns repository admission, a fresh detached worktree, its Git
observations, cancellation and the task wall-clock deadline. Each adapter
owns its subscription probe and provider protocol. Translate only bounded,
recognized evidence into the shared result. The first native identity may
arrive after the initial started receipt and cannot be replaced by a later
event. Loss with a model turn in flight is uncertain.

## Credential and process boundary

Claude retains its existing trusted entry path, scrubbed environment, project
settings checks, tool bounds and first-event credential check. Codex uses a
private stdio app-server process, a stable worker-only profile, a constrained
worktree sandbox and a ChatGPT account check before opening a model turn.
Readiness and runs verify the effective config before asking for account data
or a thread. A worker profile with user configuration is refused before the
process starts. Its dedicated ChatGPT login and native sessions stay there.
The supported setup uses a personal unmanaged Mac and a personal ChatGPT
workspace. The operator disables Codex if either becomes managed. The
worker pins SQLite and logs to its stable private profile before app-server
starts. Codex can open those stores before the first RPC. The worker refuses
contrary effective paths, routing, telemetry and tool settings before
requesting account evidence or sending work. It does not attest that a host
or workspace is unmanaged.
The worker does not read or copy authentication tokens. The protocol
client requests no interactive approvals, reads only required account
fields and carries no device credential into the child. Unsupported controls
are declared as such. Installed acceptance must verify subscription and
native-client behavior for the selected versions.
