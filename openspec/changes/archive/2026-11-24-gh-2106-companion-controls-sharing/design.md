## Control admission

The three Conversation profiles use the same private allowlist. The module binds a control to authenticated owner input in the current turn and resolves it against current state. Prior data can supply a reference. The tracked dispatcher and controller still own capability, revision, hold and writer checks.

Save the exact binding with the task before sending it. Use the existing turn step identity as the request ID. A recorded admission with a missing result is uncertain after restart, so the task never sends that request again. Correlated controller readback continues through the existing confirmation path. A refusal sends no effect and uses the existing error codes. Keep the trace through the tool call and dispatcher.

## Field grants

Keep field decisions separate from tool authority. Apply them for the caller, profile, source, purpose and destination before projection and before disclosure. A denied record contributes no counts or discovery metadata. Existing collection and private retention proceed under ADR 0011. A new destination starts with no retained fields until the owner selects them. The coding worker receives the separately approved repository and brief over its existing connection.
