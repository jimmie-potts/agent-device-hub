## Decisions

Choose Auto at admission from the current worker declaration, preferring Claude Code when both subscriptions qualify. Preserve explicit choices and leave unknown quotas unknown. Only a proved rejection makes a quota unavailable until its reset, including a rejection without a reset time. Save the route before requesting a start. Loss after dispatch gives no authority to retry or switch harnesses.

A job links immutable attempt identities. Carry the approved source attempt and a worker-issued proof through the existing tracked dispatch. The Mac worker reserves the future checkout path. Codex uses its native permissions profile to exclude that path. Claude Code launches under a macOS process sandbox that excludes writes to the same path and is inherited by its descendants. The worker verifies the boundary offline and observes process closure before issuing proof. A continuation consumes proof, rechecks root and Git-directory identities, and reproduces the accepted commit, staged index and tracked bytes in a separate Git store. The source and destination are verified after copying. Missing or changed evidence refuses continuation. The worker forwards the full approved brief with bounded Git and check facts and keeps old native session and result attribution.
