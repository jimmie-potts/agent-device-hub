## Why

B.U.N.N.Y. has virtual companion interactions but no owning Reachy device module. The accepted qualification in https://github.com/jimmie-potts/agent-device-hub/issues/619 now supplies a real MuJoCo route and bounded controls for source delivery in https://github.com/jimmie-potts/agent-device-hub/issues/621.

## What Changes

- Ship a configured Reachy module with simulated-target verification, finite gestures, explicit takeover and priority task cancellation.
- Route manual and opted-in first-live coding reactions through tracked commands, durable responsibility and the existing outcome outbox.
- Add module-owned React controls, cached status inspection and deterministic fake plus actual vendor-simulator verification.

## Capabilities

### New Capabilities

- `bunny-reachy`: bounded simulator gestures, explicit control ownership, fresh observations and honest task outcomes.

### Modified Capabilities

`bunny-sdk`: add an optional independently retained attempt key to the shared frontend Command contribution for priority cancellation. Existing companion identity, speech, lifecycle and legacy contracts retain their behavior.

## Impact

New `modules/reachy-mini`, runtime tracked-dispatch and browser admission, shared internal dispatch contract, root workspace/build/test registration and CI. Node 24 uses the existing SDK and event profile 2.0. No new package dependency, production installation, hardware access, media capture or robot audio.
