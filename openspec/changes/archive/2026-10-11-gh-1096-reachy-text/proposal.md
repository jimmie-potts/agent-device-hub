## Why

## What Changes

- Publish a bounded, first-live companion opportunity from the existing core reduction/publication path.
- Add one shipped companions module with private settings, bounded admission/presentation records and deterministic fixed text.
- Add a React Reachy page with category controls and labelled synthetic arrival scenarios.
- Cover duplicate/recovery/restart, final asynchronous validity checks, priority, social allowance and browser accessibility.

## Capabilities

### New Capabilities

- `bunny-companions`: qualified fixed-text Reachy cards, controls and isolated synthetic scenarios.

### Modified Capabilities

None. Existing core session, mode, automation and hook requirements remain in force.

Core occurrence publication, the event-contracts package, static module registration/build and existing dashboard shell. No new runtime, dependency, model/provider interface, audio or physical command. Installation remains a separately selected batch in [#643](https://github.com/jimmie-potts/agent-device-hub/issues/643).
