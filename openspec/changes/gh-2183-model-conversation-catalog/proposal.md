## Why

The hosted supervisors omit supported Conversation tools and the dispatch path compares requests with fixed English phrases. The owner needs the remaining registered controls to work in ordinary language under either supervisor.

## What Changes

- Interpret catalog actions through the current authenticated owner turn. Resolve identifiers and bind current owner revisions locally before dispatch.
- Include registered catalog commands and private draft tools in the hosted allowlist filter. Recheck existing sharing grants for tool results.
- Preserve the tracked dispatcher, owner evidence, paid artwork and coding approvals, and existing owner command payloads.

## Capabilities

### Modified Capabilities

- `bunny-assistant-tasks` covers hosted Conversation catalog admission and private draft edits.

## Impact

The Companions module owns the Conversation path. Existing Runtime, playback, Wemo, Nanoleaf, Pixoo, Tidbyt, Volcano and art owners keep their commands and state. [Hub #2183](https://github.com/jimmie-potts/agent-device-hub/issues/2183) owns this change.
