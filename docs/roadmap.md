# Delivery sequence

GitHub issues own the delivery sequence: scope, acceptance, status and
prerequisites. Follow each issue's blocked-by links for order. The
[future-work guide #35](https://github.com/jimmie-potts/agent-device-hub/issues/35)
groups later assistant, music and hosting work, and the
[cross-project work guide](work-guide/README.md) gives a dated, ordered view.
Its [Direction section](work-guide/README.md#direction-section) is the dated
narrative of where B.U.N.N.Y. stands and what to build next.

Lasting decisions live in [architecture](architecture.md), the
[decision records](decisions/), [desktop controls](desktop-controls.md) and each
controller's README.

This page used to copy issue tables and dependency chains, which went stale
whenever an issue changed. They were removed in
[#170](https://github.com/jimmie-potts/agent-device-hub/issues/170); Git history
keeps the earlier version.
