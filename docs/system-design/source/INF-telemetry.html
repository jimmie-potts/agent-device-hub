No new telemetry server selected

These responsibilities may initially use bounded local diagnostics and existing owner health/status APIs. A metrics service, log aggregator, tracing backend or message broker has not been selected. Add infrastructure only with an owner, retention policy and operational benefit.

Evidence levels

Source tests, installed client behavior, route connectivity, transport acknowledgment and physical observation are different results. A simulator image or green health check must never appear as successful visible-device acceptance. Record the tested revision and environment beside each claim.

Verification

Privacy-canary checks should inspect storage, diagnostics and errors. Test that heartbeats do not refresh evidence, queue overflow stays bounded and ambiguous writes remain visible. Performance thresholds come from the frozen baseline; new integrated stages need their own measurements.
