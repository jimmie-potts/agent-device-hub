Documentation commands

Run from the repository root. The generator uses Python’s standard library. These commands operate only on documentation.

python3 docs/system-design/build.py
python3 docs/system-design/build.py --check
python3 docs/system-design/check.py
node docs/system-design/check.cjs
python3 docs/work-guide/work/build_guide.py
python3 docs/work-guide/work/test_maintenance.py
node docs/work-guide/work/check_guide.cjs

The browser checks use an installed Playwright module and Chromium. Set GUIDE_PLAYWRIGHT_MODULE and GUIDE_CHROMIUM_PATH when discovery needs help. They never install or start BUNNY. Documentation screenshots and receipts stay outside Git.

Source editing and generation

Edit docs/system-design/source/*.html for prose and design.json for inventory/status/references. Shared appearance lives in assets/. Rebuild the individual pages, overview and complete reading view together. The generated HTML embeds its CSS/JavaScript and uses no remote runtime dependency. The separately generated Archify viewer has its own receipt and may request its template’s optional font stylesheet.

API and database reference refresh

The reference entry page links three Scalar API viewers and three SchemaSpy reports. Keep the entire reference directory when copying these pages: its local browser assets make it work offline.

Run these checks from the repository root. The ordinary checks use committed source extracts, verify generated files and start no services.

python3 docs/system-design/reference/build_api.py
python3 docs/system-design/reference/build_pages.py
python3 docs/system-design/reference/check_reference.py
node docs/system-design/reference/check_reference.cjs

To refresh source evidence, select and review immutable commits in reference/extract.py and reference/export_pixoo.mjs, then run:

python3 docs/system-design/reference/extract.py --pixoo-root <Pixoo Git repository> --nanoleaf-root <Nanoleaf Git repository>
node docs/system-design/reference/export_pixoo.mjs <Pixoo Git repository> <matching installed Pixoo dependency root>
python3 docs/system-design/reference/build_api.py
python3 docs/system-design/reference/render_schema.py --tools <verified JAR directory>
python3 docs/system-design/reference/build_pages.py

The Zod export uses Node 24 and verifies the installed Zod version against the pinned source lockfile. The renderer was verified with Java 21 and the two JARs listed in reference/tools.json. Download them separately using their recorded URLs; the renderer checks their hashes before use. It builds fresh temporary empty databases from DDL and accepts no live-database path. Graphs include declared foreign keys only.

Review route coverage, request refinements, response shapes, authentication and source hashes whenever a pin changes. Python’s explicit dispatch inventory and the response outlines need source review. SchemaSpy’s generated asset receipt detects edited output; it does not replace that review. Browser tests remain offline. Live browser testing requires a separate change in each owning service’s UI and origin boundary.
