Documentation commands

Run from the repository root. The generator uses Python’s standard library. These commands operate only on documentation.

python3 docs/system-design/build.py
python3 docs/system-design/build.py --check
python3 docs/system-design/check.py
node docs/system-design/check.cjs
python3 docs/work-guide/work/build_guide.py
python3 docs/work-guide/work/test_maintenance.py
node docs/work-guide/work/check_guide.cjs

The browser checks use an installed Playwright module and Chromium. Set GUIDE_PLAYWRIGHT_MODULE and GUIDE_CHROMIUM_PATH when discovery needs help. They never install or start BUNNY. Documentation screenshots and receipts stay outside Git.

Source editing and generation

Edit docs/system-design/source/*.html for prose and design.json for inventory/status/references. Shared appearance lives in assets/. Rebuild the individual pages, overview and complete reading view together. The generated HTML embeds its CSS/JavaScript and uses no remote runtime dependency. The separately generated Archify viewer has its own receipt and may request its template’s optional font stylesheet.
