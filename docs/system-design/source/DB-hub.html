Logical store, not a selected server

The active host provides storage through a boundary owned by the application. No new database engine, schema migration or independently deployed database is selected here. The initial embedded core can use host-owned persistence; standalone migration transfers ownership explicitly. Controller databases remain private to their controller runtimes.

For implemented schemas, open the controller database reference. Its 28 tables come from pinned Pixoo and Nanoleaf source DDL. They are not an implemented schema for the proposed B.U.N.N.Y. store.

Transactions and consistency

The core must commit a state transition and its durable notice changes coherently. Stable revisions identify committed snapshots. Publication after a committed update needs a recovery path so reconnecting clients can read authoritative state even if a change notification is lost. Exact transaction/API schema and migration code remain Q-DATA. No transaction spans a controller’s private database and B.U.N.N.Y.’s store.

Schema, indexes and examples

Entity names above are conceptual, not physical SQL tables. Implementation must define types, nullability, uniqueness, indexes, migration history and compatibility beside the owning code. Candidate indexes follow the actual session selector, notice/consumer identity and rule execution identity. Do not publish guessed migrations as an implemented database schema.

Use neutral fixture identifiers such as host-demo, session-demo and desk-display. Real credentials, private paths, prompts, transcripts and device addresses do not belong in fixtures or Git.

Migration and verification

  • Name the single migration executor and supported old/new versions before rollout. Test interrupted migration, restore and duplicate/concurrent operations.
  • A stopped-writer export/import must preserve identities, notices, revisions and selected labels when moving an existing shared owner.
  • The accepted fresh Nanoleaf Linux installation is a separate exception owned by Hub #43 and Nanoleaf #54/#55; it is not a generic rule to discard shared B.U.N.N.Y. state.
