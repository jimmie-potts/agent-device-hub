Meaning and status

A track-change event means an observed content transition in the selected playback session. It does not mean beat, volume or spectrum. No versioned playback wire schema exists in this baseline. The field set and identity algorithm must follow Windows qualification under Hub #36.

Processing semantics

The playback owner produces the interpreted change. The UI receives current state independently; rules consume qualified changes. A reconnect snapshot should not automatically replay a lighting action for every previously observed song. The initial-snapshot and resume/repeat policies must be chosen explicitly in Q-MUSIC.
