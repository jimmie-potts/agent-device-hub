Status and target

LIFX currently has design documents, not an implemented controller in this repository. The selected direction is direct LAN control. The recorded “A16” model is unconfirmed; do not assume A19, color support or a particular effect interface. Home Assistant is not a dependency of this controller.

Command ownership

Map advertised common capabilities onto the qualified device/library interface. Maintain one designated writer and queue per configured bulb. Clients select neutral registered IDs, never raw addresses or packets. Missing acknowledgments remain uncertain; health, desired state, observations and visible lighting are distinct.

Policy and failure

The automatic-status issue owns group mapping, multi-session policy, brightness limits, quiet/disabled behavior and manual-control restoration. A stalled bulb must not block another device or a provider hook. Source setup uses fakes and never scans the LAN.

Verification

Qualify the exact device model and transport, then implement fake packet checks, shared-state consumption and separately authorized installed/physical acceptance. Container reachability is an additional deployment test, not a consequence of source compatibility.
