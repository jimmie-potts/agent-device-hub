State ownership

The installed hub owns shared playback in a module separate from agent state. The Sony HT-A9 source (Hub #175) and Sonos Move source (Hub #233) observe Apple Music played from the iPhone over AirPlay; audio never passes through the hub. Each source owns its protocol and field mapping. The shared module retains normalized observations, freshness and command results, and exposes one stable playback ID to clients. Now-playing is installed and checked under Hub #37.

The Windows music connector (Hub #36) is deferred. If built, it becomes another source of this module and stays PC-local, using a relay when the runtime moves to the Linux server under ADR 0008.

Controls and failure

An explicit UI/MCP Next request names the stable playback ID. The hub ranks sources by whether they report a playing or paused session, then by freshness class (available, stale, unavailable), then by configured order. It sends a supported command only to the presented source. Commands do not pass through agent state or require an automation rule, and are never redirected, retried or replayed.

A timeout after possible dispatch remains uncertain; re-read playback evidence before another explicit action. Failed reads age only that source’s retained observation. A stale presented source rejects commands and can remain visible until its session expires; missing evidence never implies paused playback. Source loss does not stop unrelated local device control. Next and previous while paused were checked on the Move: the phone changes track, but the Move keeps the old title until playback resumes, as the HT-A9 does.

Verification and open choices

  • Qualify Windows metadata, session selection, supported controls and refresh behavior under Hub #36.
  • Test duplicate observations, same-song repeat/restart, reconnect and missing track identity before promising track-change semantics.
  • Music metadata is an explicitly selected domain. It must not be copied into the allowlisted agent lifecycle feed. Artwork access, caching and retention remain Q-MUSIC.
  • Audio levels and spectrum are a separate input under Hub #41. A track change cannot establish sound intensity or synchronized animation.
