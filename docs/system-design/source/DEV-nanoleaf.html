Process and data ownership

In the fresh Linux arrangement, hooks, wall map, controller and worker coordinate through private Linux SQLite. The existing on-demand worker remains the sole writer to the lights. MCP communicates with the protected controller over HTTP. Windows Desktop/browser clients and configured mounted JSON metadata reads do not own that database. No cross-OS live SQLite sharing is introduced.
