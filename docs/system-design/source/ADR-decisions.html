Patterns and their placement

PatternB.U.N.N.Y. usePractical limit
Ports and adaptersKeep provider/device/storage details behind explicit interfaces.A logical interface does not require a new process.
Service Layer / FacadeUI, MCP and approved actions call common owning operations.Authentication and transport parsing stay at the boundary.
AdapterNormalize provider observations and translate supported controller interfaces.Do not hide unsupported capabilities.
CommandCarry explicit intent, target and request identity.No automatic guarantee of undo or exactly-once physical effects.
ObserverDeliver interpreted state to interested UI/policy consumers.No implied broker or permanent replay log.
StrategySelect replaceable policy where behavior actually varies.Use ordinary functions/interfaces when sufficient.
Deterministic reducerCompute agent state with explicit inputs and clock.Task state does not require a GoF State class hierarchy.

Document authority

GitHub issues own acceptance and status. Existing architecture/ADRs own accepted decisions. Published schemas own wire values. These HTML pages organize the design and expose gaps; they do not silently resolve the questions above. Record a new lasting choice in the owning ADR/specification before treating it as accepted behavior.
