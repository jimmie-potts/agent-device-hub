Backup and restore

Select backing paths, access permissions, retention, backup destination and recovery objectives under Q-DATA/Q-DEPLOY. Verify restore into isolated storage before claiming recoverability. Do not copy a live cross-OS SQLite file or let multiple pods open one private database as an ownership mechanism.

Verification

Exercise restart, interrupted migration, restore, cluster recreation and explicit reset using synthetic data. Record what survived and which owner accessed it. The Nanoleaf fresh-install exception remains scoped to its owning migration; it does not erase B.U.N.N.Y.’s future shared-state preservation requirements.
