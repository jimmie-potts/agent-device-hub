Client boundary

The browser uses authenticated application operations and status feeds. It never opens a controller database, schedules physical animations or writes directly to vendor APIs. A UI refresh cannot acknowledge notices or refresh device evidence. On reconnect, recover from authoritative snapshots and display stale facts honestly.

Accessibility and verification

  • Use keyboard-accessible controls, visible focus, readable status text and color-independent uncertainty labels.
  • Test capability absence, authorization changes, duplicate clicks, response loss, stale feeds and independent device failures with fakes.
  • Choose the frontend build, route and authentication details in Hub #6. Human approval of the current candidate precedes delivery; installed and physical results have their own gates.
