Local-first access

Start with explicit local access. Loopback names are local to their process network environment; Windows, WSL, Docker and kind paths must be qualified independently. A container’s healthy HTTP endpoint does not establish a route to LAN hardware or the Windows media session. Remote phone/voice access remains Hub #47/#48.

Security and operational checks

  • Use configured destinations and independent machine credentials. Keep browser tokens and provider input out of controller forwarding.
  • Verify current authorization on reads, writes and replay. Record rotation/revocation behavior.
  • Test a permitted caller, denied caller, unsupported route, disconnected adapter and bounded timeout.
  • No public ingress, tunnel, router, firewall or device address is selected by this document.
