How the architecture evolved

These views preserve earlier designs for comparison. They describe their dated baselines, not today’s running system.

September 2026 · Separate services

The Hub interpreted agent state and called independent Nanoleaf and Pixoo services through controller-v1 APIs. Each service owned its device queues and private stores.

Open the preserved system map · September design atlas

October 2026 · One runtime, then a new host

The October 9 cutover replaced the separate services with one TypeScript runtime and the profile-2.0 SDK bus. The October 31 household cutover brought selected device modules onto the existing Mac core, using fresh module state. Old stores and services stayed stopped and retained.
